📱 LINE プッシュ連携 セットアップ手順

SCHEDULE STUDIO の INFO 投稿を、スタッフの LINE に自動配信できるようにする手順です。
所要時間：約 30 分（初回のみ）。

全体像：
PC アプリ → Google Apps Script (中継) → LINE Messaging API → スタッフの LINE

Phase 1：LINE Bot を作る（10分）

1LINE Developers Console を開く
のむさんの LINE アカウントでログインしてください
2プロバイダー新規作成
名前は何でも OK（例：「Schedule Studio」）
3Messaging API チャネル新規作成
  • Channel name：例「Schedule Studio Bot」
  • Channel description：例「ツアー進行通知」
  • Category / Subcategory：エンタメ系を選択
  • 規約に同意 → 作成
4Channel access token (long-lived) を発行
チャネル設定 → 「Messaging API」タブ → 一番下「Channel access token」→ Issue ボタン
発行された長い文字列をコピー（あとで使う）
5応答メッセージを OFF に
「Messaging API」タブ → LINE Official Account features →「応答メッセージ」を 無効 に
（Bot が自動返信しないようにするため）
6QR コードを取得
同じ「Messaging API」タブの上部にある QR コードを保存
→ スタッフ全員 にこの QR を配って、Bot を友だち追加してもらう

Phase 2：Google Apps Script で中継を作る（10分）

1Google Apps Script を開く
のむさんの Google アカウントでログイン
2「新しいプロジェクト」 をクリック
3左の コード.gs の中身を全部消して、下のコードを貼り付け： 
// SCHEDULE STUDIO — LINE 中継 (Google Apps Script)
// 1. LINE_TOKEN に Phase 1 で発行した Channel access token を貼る
// 2. デプロイ → ウェブアプリ → アクセス：全員 → デプロイ
// 3. URL を SCHEDULE STUDIO の INFO タブの「LINE 連携 設定」に貼る

const LINE_TOKEN = 'ここに Phase 1-4 で取得した Channel access token を貼る';

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);
    const lines = [];
    if (data.concert) lines.push('🎤 ' + data.concert);
    if (data.subject) lines.push('【' + data.subject + '】');
    if (data.body)    lines.push(data.body);
    if (data.sender)  lines.push('— ' + data.sender);
    if (data.sentAt)  lines.push(data.sentAt);
    const text = lines.join('\n');

    const res = UrlFetchApp.fetch('https://api.line.me/v2/bot/message/broadcast', {
      method: 'post',
      contentType: 'application/json',
      headers: { Authorization: 'Bearer ' + LINE_TOKEN },
      payload: JSON.stringify({
        messages: [{ type: 'text', text: text }]
      }),
      muteHttpExceptions: true
    });
    return ContentService.createTextOutput(JSON.stringify({
      ok: res.getResponseCode() === 200,
      code: res.getResponseCode(),
      response: res.getContentText()
    })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({
      ok: false, error: err.message
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet() {
  return ContentService.createTextOutput('SCHEDULE STUDIO LINE 中継：稼働中');
}
4LINE_TOKEN の行を編集
'ここに Phase 1-4 で取得した Channel access token を貼る' の中身を、Phase 1-4 で取得した token に置き換え
5右上「保存」（フロッピーディスクアイコン）→ プロジェクト名を入力（例「Schedule Studio LINE 中継」）
6右上「デプロイ」→「新しいデプロイ」
  • 左の歯車アイコン →「ウェブアプリ」を選択
  • 「次のユーザーとして実行」：自分
  • 「アクセスできるユーザー」：全員（重要！「自分のみ」だと動きません）
  • 「デプロイ」をクリック
  • 初回は権限承認画面が出る → 進めて承認
7デプロイ後の URL をコピー
https://script.google.com/macros/s/AKfy.../exec という形の URL が表示される → コピー

Phase 3：SCHEDULE STUDIO に URL を貼る（1分）

1PC で pc-edit.html を開く → INFO タブ
2「⚙ LINE 連携 設定（初回のみ）」を開く
URL 欄に Phase 2-7 でコピーした GAS の URL を貼り付け → 「保存」
3「テスト送信」 をクリック
友だち追加してる LINE に「SCHEDULE STUDIO からのテスト配信です。」が届けば成功

本番運用

あとは INFO タブで件名・本文を入れて 📱 LINE プッシュ送信 を押すだけで、Bot を友だち追加した全員に配信されます。

困ったとき

症状原因と対処
テスト送信したのに LINE 来ない(1) Bot を友だち追加してない (2) GAS の LINE_TOKEN が間違ってる (3) GAS デプロイ時「アクセス：全員」になってない
「LINE 配信に失敗」と出るGAS URL が間違ってる、または GAS が削除されてる
応答メッセージが届くPhase 1-5 の「応答メッセージを OFF」を忘れてる
broadcast の月間制限が来た無料プランは月 200 通まで。超過したら 200 名以下のグループ運用なら問題ない
セキュリティ注意：GAS URL を知ってる人なら誰でも LINE に送信できます。SNS や公開リポジトリには貼らないでください。
