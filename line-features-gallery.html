SCHEDULE STUDIO · LINE Bot Features

LINE Bot 機能カタログ

SCHEDULE STUDIO の LINE 連携で使える機能を、実際のトーク画面に近いモックで一覧化しました。緑のエリアが LINE のグループ・トーク画面で、白いカードや吹き出しが Bot から届くメッセージのイメージです。「これいいね」のやつを 1〜複数選んでください、実装します。

01
テキスト Push
Text Push Message
一番シンプル。Bot から文字メッセージを送る。短い連絡・お知らせ向け。今 INFO 配信で使ってるやつ。
SS
SCHEDULE STUDIO
【テスト4】
■ 楽屋の水補充お願いします
― 17:42 ―
17:42 既読 4
用途: 緊急連絡 / 短い指示 / 報告
